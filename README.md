# CS50 Validador de Cartão
Este projeto foi desenvolvido em Python durante o curso CS50 (CC50) com o objetivo de simular a verificação da validade de cartões de crédito.

## Funcionalidades
- Analisa o número informado pelo usuário
- Aplica o Algoritmo de Luhn para validar o cartão
- Identifica a bandeira com base em padrões de numeração

## Como executar
```
git clone https://github.com/dev-pedr0/CS50_credit_python
cd nome-do-projeto
python credit.py
```
